## ضوابط
- لا يُكتب فوق نسخة احتياطية دون تأكيد.
- تستخدم معاملات SQL للعمليات المالية.
- لا يُعتمد ترحيل قاعدة البيانات قبل مطابقة أعداد السجلات والأرصدة والتقارير مع المصدر.
- الباركود الداخلي لا يحل محل GTIN/EAN المسجل عند الحاجة للبيع خارج النظام.
