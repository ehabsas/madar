## ضوابط
- لا يُكتب فوق نسخة احتياطية دون تأكيد.
- تحفظ كل عملية مالية وحركة مخزون داخل معاملة SQL متى كانت مرتبطة.
- لا يعتمد ترحيل قاعدة البيانات قبل مطابقة أعداد السجلات والأرصدة والتقارير مع المصدر.
- الباركود الداخلي `MAD...` ليس GTIN/EAN عالميًا.
- إضافة ملفات بناء لا تعني أن الملفات التنفيذية لكل منصة قد بُنيت أو اختُبرت بالفعل.
