قواعد الباركود

  • نحافظ على الباركود القديم إذا كان موجودًا وفريدًا.
  • لو مش موجود، يُنشأ باركود داخلي بصيغة MAD متوافق مع الطباعة عبر Code 128.
  • يمكن لاحقًا إضافة باركودات متعددة للصنف حسب العبوة أو الوحدة.
  • الباركود الداخلي لا يُعد رقم GTIN عالميًا ولا يُستخدم كبديل لباركود تجاري مسجل.
